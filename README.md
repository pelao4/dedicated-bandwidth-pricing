## 算一笔月账单：端口费之外还有什么

把一次性费用、端口费和流量费加在一起，账单才算完整。三个例子：

- 北京企业办 10M 互联网专线（接入层静态路由）：首月 5280 元（含 100 元开户费），之后每月 5180 元，IP 够用就不再加钱
- 混合云场景，10GE 独享端口，每月出方向 10TB：腾讯云约 6024 元/月（5000 元端口费 + 10240GB × 0.1 元），京东云约 5019 元/月
- 腾讯云的官方计费示例更直观：同一账号下三个专线网关合计出方向 120TB，单月流量费 12288 元

规律很直接：端口越小，流量费在账单里的占比越高。千兆端口只要 600 元/月，但 10TB 出方向流量就要 1024 元，流量反超端口费。先估算流量模型，再谈端口价格，顺序别反了。如果这些标准档位都套不上你的需求，第三方服务商的按需报价可以作为参照：[👉 对比MKCloud的套餐和计费方式](https://bit.ly/mkcloud)。

## 同样叫专线，报价差在哪

五个变量决定了你最终拿到的数字：

1. **接什么网**：互联网专线卖的是公网独享带宽和固定 IP；云专线只是到云内网的管道，流量费另算。同样是"100M"，前者 45700 元/月起，后者共享通道只要 200 元/月，差的是两个市场
2. **在哪接**：城市等级和接入层级各能拉开 5%–20%
3. **怎么路由**：BGP 全穿透比静态路由贵五到七成
4. **要不要 SLA**：紫金、黄金、白金等级分别上浮 10%、20%、25%
5. **线路施工**：光缆铺设费、楼内线缆租赁费不在标准资费里，工勘后才出数。一个细节：京东云宿迁接入机房是自建的，不收楼内线缆租赁费，其它中立机房通常要收

## 常见问题

### 100M 专线一个月多少钱？

分两条线。公网互联网专线：联通一类城市接入层 45700 元/月、汇聚层 57200 元/月（标准价，可谈下浮）。上云的 100M 共享专用通道：腾讯云 200 元/月，另加出方向流量费。差距源于两类产品卖的东西不同，见上一节。

### 专线费用是一次付清还是按月交？

按月为主。一次性费用有三类：开户/初装费（联通 100 元，阿里云 1500 美元）、光缆铺设费，以及可能的楼内线缆租赁费。端口费京东云按月预付，腾讯云按月后付。

### 专线价格还能往下谈吗？

运营商可以：联通允许各省公司在标准资费基础上最多下浮 15%，SLA 等级和未列明速率的折算方式也能协商。云厂商端口费为公示价，能优化的主要是流量成本。
